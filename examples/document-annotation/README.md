# 文档标注动画示例

本目录由以下命令生成：

```bash
python scripts/create_document_annotation_demo.py
```

渲染：

```bash
.venv/Scripts/python.exe scripts/render_document_annotation.py \
  examples/document-annotation/project.json \
  examples/document-annotation/demo.mp4
```

配置包含两页 720×1280 文档、圈选、下划线、箭头、越南语批注、手部覆盖和缓慢镜头移动。
